# Лабораторная работа 7 — Структуры и работа с файлами

**Вариант:** 10

## Задание

Файл содержит сведения об автомобилях: марка, год выпуска, фамилия владельца и номер. Программа выводит автомобили заданной марки, вычисляет их средний возраст и находит самый старый автомобиль среди всех записей.

## Файлы проекта

- `main.cpp` — исходный код программы.
- `input.txt` — пример входных данных.
- `output.txt` — файл для результата работы программы.

## Формат входного файла

Одна запись располагается в одной строке. Поля разделяются точкой с запятой:

`Марка;Год;Фамилия;Номер`

Пример:

```text
Toyota;2018;Иванов;А123ВС
BMW;2012;Петров;К456МН
Lada;2008;Сидоров;О789РТ
```

Файл не должен содержать заголовок. Максимальное количество записей — 100.

## Компиляция и запуск

Для компиляции требуется компилятор с поддержкой C++11 или новее.

```bash
g++ -std=c++11 main.cpp -o lab7
```

Запуск:

```bash
./lab7
```

В Windows:

```text
lab7.exe
```

После запуска программа запрашивает путь к входному файлу, путь к выходному файлу и марку автомобиля для поиска. Если файлы находятся в рабочей папке программы, можно указать `input.txt` и `output.txt`.

## Результат

Отчёт выводится в консоль и одновременно сохраняется в указанный выходной файл. В отчёте отображаются найденные автомобили, средний возраст автомобилей заданной марки и самый старый автомобиль из всего файла.

Если автомобилей заданной марки нет, выводятся `Cars: NONE` и `Average age: NONE`. Если входной файл пуст, самый старый автомобиль также обозначается как `NONE`.

## Проверки

Программа проверяет открытие входного файла, число полей, заполнение обязательных текстовых полей, корректность года выпуска, ограничение в 100 записей и успешность записи отчёта. При ошибке строки выводится её номер, обработка прекращается без формирования частичного отчёта.
